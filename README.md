# Notes

This repository is set up for note-taking using Git as the version control system.

## Notes structure

- `notes/template.md` — starter template for new notes
- `notes/YYYY-MM-DD.md` — daily notes
- `notes/project-name.md` — project-specific notes

## How to use

1. Add a new note in `notes/`
2. Commit each update with a clear message
3. Use branches for separate projects or topics
4. Use tags for milestones or important versions
