Fungsi Spreadsheet untuk Random Variable Diskrit, Kontinu, dan Bivariat

Penulis

OpenAI

1 Pendahuluan

Dokumen ini merangkum fungsi-fungsi spreadsheet yang berguna untuk mempelajari random variable diskrit, random variable kontinu, dan random variable bivariat. Contoh-contoh ditulis dalam format yang umum dipakai di Microsoft Excel dan sebagian besar juga dapat digunakan di Google Sheets.

Tujuan dokumen ini adalah membantu pembaca:

  1. mengenali fungsi-fungsi penting untuk simulasi dan analisis probabilistik,
  2. memahami cara memakai rumus-rumus spreadsheet secara langsung,
  3. menghubungkan konsep peluang, ekspektasi, variansi, kovariansi, dan korelasi dengan praktik komputasi sederhana.

2 Random Variable Diskrit

Random variable diskrit adalah peubah acak yang nilainya dapat dihitung satu per satu, misalnya banyaknya pelanggan datang, jumlah keberhasilan, atau hasil lemparan dadu.

2.1 Membuat Nilai Acak Diskrit

2.1.1 Fungsi RANDBETWEEN

Fungsi ini menghasilkan bilangan bulat acak antara batas bawah dan batas atas.

=RANDBETWEEN(1,6)

Contoh ini dapat dipakai untuk mensimulasikan satu kali lemparan dadu.

2.2 Distribusi Bernoulli

Distribusi Bernoulli memiliki dua hasil: sukses (1) atau gagal (0).

2.2.1 Simulasi Bernoulli dengan IF dan RAND

Misalkan peluang sukses adalah 0.3.

=IF(RAND()<0.3,1,0)

Rumus ini menghasilkan:

  • 1 dengan peluang 0,3
  • 0 dengan peluang 0,7

2.3 Distribusi Binomial

Distribusi binomial memodelkan banyaknya sukses dari n percobaan independen.

2.3.1 Fungsi BINOM.DIST

Bentuk umum:

=BINOM.DIST(x,n,p,kumulatif)

Keterangan:

  • x: jumlah sukses
  • n: jumlah percobaan
  • p: peluang sukses tiap percobaan
  • FALSE: peluang tepat
  • TRUE: peluang kumulatif

2.3.2 Contoh peluang tepat

Peluang tepat 3 sukses dari 10 percobaan, dengan peluang sukses 0,4:

=BINOM.DIST(3,10,0.4,FALSE)

2.3.3 Contoh peluang kumulatif

Peluang paling banyak 3 sukses:

=BINOM.DIST(3,10,0.4,TRUE)

2.4 Distribusi Poisson

Distribusi Poisson sering dipakai untuk memodelkan banyak kejadian dalam suatu interval waktu atau ruang.

2.4.1 Fungsi POISSON.DIST

=POISSON.DIST(x,lambda,kumulatif)

2.4.2 Contoh peluang tepat

Peluang tepat 4 kejadian saat rata-rata kejadian 2.5:

=POISSON.DIST(4,2.5,FALSE)

2.4.3 Contoh peluang kumulatif

Peluang paling banyak 4 kejadian:

=POISSON.DIST(4,2.5,TRUE)

2.5 Distribusi Geometrik

Distribusi geometrik memodelkan kapan sukses pertama terjadi.

2.5.1 Fungsi GEOM.DIST

=GEOM.DIST(x,p,kumulatif)

Contoh peluang sukses pertama terjadi pada percobaan ke-4 dengan peluang sukses 0,2:

=GEOM.DIST(4,0.2,FALSE)

2.6 Ekspektasi Random Variable Diskrit

Jika nilai-nilai acak berada pada rentang A2:A6 dan peluangnya pada B2:B6, maka nilai harapan dapat dihitung dengan SUMPRODUCT.

2.6.1 Fungsi SUMPRODUCT

=SUMPRODUCT(A2:A6,B2:B6)

Contoh tabel:

Nilai (x) Peluang (P(X=x))
0 0.1
1 0.2
2 0.4
3 0.2
4 0.1

Rumus ekspektasi:

=SUMPRODUCT(A2:A6,B2:B6)

2.7 Variansi Random Variable Diskrit

Gunakan rumus:

\[ Var(X)=E[X^2]-(E[X])^2 \]

Jika nilai (x) di A2:A6 dan peluang di B2:B6, salah satu cara adalah langsung memakai:

=SUMPRODUCT((A2:A6^2),B2:B6)-(SUMPRODUCT(A2:A6,B2:B6))^2

Dalam praktik spreadsheet, sering lebih aman memakai kolom bantu.

Misalkan di C2 tulis:

=A2^2

lalu salin ke bawah, dan hitung variansi dengan:

=SUMPRODUCT(C2:C6,B2:B6)-(SUMPRODUCT(A2:A6,B2:B6))^2

3 Random Variable Kontinu

Random variable kontinu mengambil nilai pada suatu interval, misalnya tinggi badan, berat badan, waktu tunggu, dan temperatur.

3.1 Membuat Nilai Acak Uniform

3.1.1 Fungsi RAND

Fungsi ini menghasilkan angka acak antara 0 dan 1.

=RAND()

3.1.2 Uniform pada interval tertentu

Untuk menghasilkan data acak uniform pada interval ([a,b]):

=a + (b-a)*RAND()

Contoh interval 10 sampai 20:

=10 + (20-10)*RAND()

3.2 Distribusi Normal

Distribusi normal sangat penting dalam statistika karena banyak fenomena alam dan sosial mendekatinya.

3.2.1 Fungsi NORM.DIST

=NORM.DIST(x,mean,std_dev,kumulatif)

3.2.2 Contoh densitas

Nilai densitas pada x = 70, mean 65, standar deviasi 8:

=NORM.DIST(70,65,8,FALSE)

3.2.3 Contoh peluang kumulatif

Peluang (X ):

=NORM.DIST(70,65,8,TRUE)

3.3 Membuat Sampel Acak Normal

3.3.1 Fungsi NORM.INV

Salah satu cara menghasilkan data normal acak adalah dengan mengubah uniform acak menjadi normal menggunakan inverse CDF.

=NORM.INV(RAND(),65,8)

Rumus ini menghasilkan satu sampel acak dari distribusi normal dengan mean 65 dan simpangan baku 8.

3.4 Distribusi Eksponensial

Distribusi eksponensial sering digunakan untuk memodelkan waktu antar-kejadian.

3.4.1 Fungsi EXPON.DIST

=EXPON.DIST(x,lambda,kumulatif)

3.4.2 Contoh densitas

Nilai densitas pada x = 2 dengan laju 0.5:

=EXPON.DIST(2,0.5,FALSE)

3.4.3 Contoh peluang kumulatif

Peluang (X ):

=EXPON.DIST(2,0.5,TRUE)

3.5 Membuat Sampel Acak Eksponensial

Dengan transformasi invers, distribusi eksponensial dapat disimulasikan melalui:

=-LN(1-RAND())/0.5

Rumus ini menghasilkan sampel acak eksponensial dengan parameter laju 0.5.

3.6 Rata-rata dan Variabilitas Data Kontinu

Misalkan data berada pada rentang A2:A101.

3.6.1 Mean

=AVERAGE(A2:A101)

3.6.2 Variansi sampel

=VAR.S(A2:A101)

3.6.3 Variansi populasi

=VAR.P(A2:A101)

3.6.4 Simpangan baku sampel

=STDEV.S(A2:A101)

3.6.5 Simpangan baku populasi

=STDEV.P(A2:A101)

4 Random Variable Bivariat

Random variable bivariat melibatkan dua peubah acak yang diamati bersama-sama, misalnya tinggi dan berat, nilai UTS dan UAS, atau permintaan dan biaya.

Misalkan:

  • data (X) berada di kolom A
  • data (Y) berada di kolom B

4.1 Mean Masing-masing Variabel

Untuk (X):

=AVERAGE(A2:A101)

Untuk (Y):

=AVERAGE(B2:B101)

4.2 Variansi Masing-masing Variabel

Untuk (X):

=VAR.S(A2:A101)

Untuk (Y):

=VAR.S(B2:B101)

4.3 Kovariansi

Kovariansi mengukur kecenderungan dua variabel berubah bersama.

4.3.1 Fungsi COVARIANCE.S dan COVARIANCE.P

Untuk sampel:

=COVARIANCE.S(A2:A101,B2:B101)

Untuk populasi:

=COVARIANCE.P(A2:A101,B2:B101)

Interpretasi umum:

  • bernilai positif: jika X naik, Y cenderung naik,
  • bernilai negatif: jika X naik, Y cenderung turun,
  • mendekati nol: hubungan linear lemah.

4.4 Korelasi

Korelasi menormalkan kovariansi sehingga nilainya berada pada interval ([-1,1]).

4.4.1 Fungsi CORREL

=CORREL(A2:A101,B2:B101)

Interpretasi umum:

  • mendekati 1: hubungan linear positif kuat,
  • mendekati -1: hubungan linear negatif kuat,
  • mendekati 0: hubungan linear lemah.

4.5 Regresi Linear Sederhana

Jika ingin memodelkan hubungan linear (Y) terhadap (X), spreadsheet menyediakan fungsi berikut.

4.5.1 Kemiringan garis regresi: SLOPE

=SLOPE(B2:B101,A2:A101)

4.5.2 Intersep garis regresi: INTERCEPT

=INTERCEPT(B2:B101,A2:A101)

4.5.3 Prediksi nilai Y

Jika nilai X tertentu berada di sel A2, maka prediksi (Y) adalah:

=INTERCEPT(B2:B101,A2:A101) + SLOPE(B2:B101,A2:A101)*A2

4.6 Joint Distribution Diskrit Bivariat

Jika dua variabel diskrit diamati bersama, peluang gabungannya dapat dihitung dengan COUNTIFS.

Misalkan:

  • data X pada A2:A101
  • data Y pada B2:B101

4.6.1 Peluang bersama

Contoh menghitung (P(X=1, Y=2)):

=COUNTIFS(A2:A101,1,B2:B101,2)/COUNT(A2:A101)

4.6.2 Peluang marginal

Contoh menghitung (P(X=1)):

=COUNTIF(A2:A101,1)/COUNT(A2:A101)

4.6.3 Peluang kondisional

Contoh menghitung (P(Y=2 X=1)):

=COUNTIFS(A2:A101,1,B2:B101,2)/COUNTIF(A2:A101,1)

4.7 Expected Value pada Joint Distribution

Misalkan tabel peluang gabungan disusun sebagai berikut:

  • nilai X di B1:E1
  • nilai Y di A2:A5
  • probabilitas gabungan di B2:E5

Dalam praktik, perhitungan ekspektasi gabungan sering memerlukan tabel bantu.

4.7.1 Menghitung (E[X])

Secara konseptual, kita jumlahkan semua nilai X dikalikan probabilitas marginalnya. Jika struktur tabel sudah sesuai, SUMPRODUCT dapat digunakan.

4.7.2 Menghitung (E[XY])

Buat matriks hasil kali x*y, lalu kalikan dengan matriks probabilitas bersama:

=SUMPRODUCT(matriks_XY, matriks_probabilitas)

5 Fungsi Penting Lain yang Sering Dipakai

5.1 Frekuensi dan Histogram

5.1.1 Fungsi FREQUENCY

=FREQUENCY(A2:A101,D2:D6)

Fungsi ini berguna untuk membuat distribusi frekuensi empiris atau histogram.

5.2 Persentil dan Kuartil

5.2.1 Persentil

=PERCENTILE.INC(A2:A101,0.25)

5.2.2 Median

=MEDIAN(A2:A101)

5.2.3 Kuartil

=QUARTILE.INC(A2:A101,3)

5.3 Nilai Minimum dan Maksimum

=MIN(A2:A101)
=MAX(A2:A101)

5.4 Menghitung Peluang Empiris

Jika nilai tertentu ditulis di D2, maka jumlah kemunculannya dapat dihitung dengan:

=COUNTIF(A2:A101,D2)

Peluang empirisnya:

=COUNTIF(A2:A101,D2)/COUNT(A2:A101)

Pada sel A2, tulis:

=NORM.INV(RAND(),170,8)

6.3 Contoh 3: Tinggi dan Berat sebagai Data Bivariat

Misalkan:

  • berat di B2:B101

6.3.1 Kovariansi

=COVARIANCE.S(A2:A101,B2:B101)

6.3.2 Korelasi

=CORREL(A2:A101,B2:B101)

6.3.3 Slope regresi berat terhadap tinggi

=SLOPE(B2:B101,A2:A101)
